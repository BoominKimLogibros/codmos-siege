# 권지용

사용자 제공 `gdragon-jet-all-motions-20261030.zip`에서 게임에 필요한 4방향 이동·공격·방어, 좌우 달리기, 실패·승리 동작 20개 PNG·JSON 쌍을 원본 바이트 그대로 복사했습니다. 24fps와 발 기준 anchor를 유지합니다. 추가 점프·슬라이드 동작은 현재 게임 조작에 연결하지 않았습니다.

- 원거리 기본 공격, 금색 스킬 이펙트, 왕관 모양 패시브 표식.
- P 앵콜 템포: 살아 있는 적 유닛에게 기본 공격 5회 적중 시 마나 30 회복과 3초간 공격속도 40% 증가. 포탑·스킬·빗나간 공격은 중첩되지 않으며 부활 시 초기화.
- Q 골든 비트: 조준 방향으로 금빛 투사체 3개를 부채꼴로 발사.
- W 스웨그 실드: 자기 보호막과 4초 이동속도 강화.
- E 무대 전환: 조준 지점으로 짧게 순간이동하며 주변 적 공격.
- R 크라운 피날레: 선택 구역에 연속 포격.

Q/E/R은 키를 누르면 조준하고 놓으면 공격 제스처 후 발동합니다. Esc로 조준 취소. W는 방어 제스처 후 자기 강화. 공통 18레벨·스킬 강화·아이템·피격 tint를 사용합니다.

출처와 파일 해시: [ASSET-SOURCE.json](../../public/survival/character-sprites/gdragon/ASSET-SOURCE.json). HUD 아이콘은 프로젝트의 기존 라이선스 에셋 재사용.

검증: `npm run check:character -- gdragon`, `npm test`, `npm run build`.
