# 카리나

사용자 제공 `karina-isabele-all-motions-neck-fixed-20261030.zip`에서 목 연결 보정이 적용된 `br_isabele` 스프라이트를 가져왔습니다. 게임에 필요한 20개 PNG·JSON 쌍을 원본 바이트 그대로 복사했습니다. 추가 댄스·점프·슬라이드 동작은 현재 게임 상태에 연결되지 않아 가져오지 않았습니다.

- 원거리 기본 공격. 청록색 스킬 이펙트와 네온 리듬 전용 패시브 표식.
- P 네온 리듬: 시전이 완료된 스킬 3회마다 65 + 주문력 35%의 보호막. 회복·보호막 강화 적용. 사망 후 부활 시 중첩 초기화. 취소된 시전은 계산하지 않음.
- Q 프리즘 펄스: 조준한 직선을 관통하는 마법 광선.
- W 스포트라이트: 자기 보호막과 3초 이동속도 강화.
- E 싱크 스텝: 조준 방향으로 돌진하며 경로의 적 공격.
- R 슈퍼노바 스테이지: 선택한 범위에 4초간 지속 피해와 둔화.

Q/E/R은 키를 누르면 조준하고 놓으면 공격 준비 제스처 후 시전하며 Esc로 취소합니다. W는 방어 제스처 후 자신에게 발동합니다. 공통 스킬 강화·18레벨·아이템·피격 tint 시스템을 사용합니다.

레벨 1: 체력 400, 체력 재생 6.5/5초, 마나 330, 마나 재생 10/5초, 공격력 23, 공격속도 약 1.11/초, 주문력 22, 방어력 27, 마법저항력 32, 이동속도 365.

원본 출처 및 40개 파일 해시: [ASSET-SOURCE.json](../../public/survival/character-sprites/karina/ASSET-SOURCE.json). 아이콘은 프로젝트에서 사용 중인 같은 라이선스의 기존 스킬 그림을 재사용합니다.

검증: `npm run check:character -- karina`, `npm test`, `npm run build`. 실제 브라우저에서 선택·4방향 이동·Q 조준 및 공격 제스처 후 시전을 확인했습니다.
