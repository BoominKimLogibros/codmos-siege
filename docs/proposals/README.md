# 기획 제안서

이 양식을 복사해 이 폴더에 안건명.md를 추가한 뒤 PR을 보내 주세요. 필요한 항목만 채워도 됩니다. 기존 동작과 새 제안을 구분하고, 수치가 초안이면 표시해 주세요.

## 제안명

- 분야: 캐릭터 / 게임 규칙 / 아이템 / 밸런스 / 아트·UI / 기타
- 상태: 아이디어 / 상세 기획 / 구현 포함

## 목적

현재 어떤 문제가 있고, 누구에게 어떤 재미나 개선을 제공하나요?

## 제안 내용

플레이 상황과 변경 후 동작을 설명해 주세요.

### 캐릭터 제안인 경우

- 이름·역할·특징, 강점과 약점
- 기본 공격과 주요 능력치
- 패시브 / Q / W / E / R: 조작 방식, 효과, 사거리, 재사용 대기시간, 자원 소모
- 레벨·스킬 랭크에 따른 성장, 상대가 대응할 방법

### 아이템 제안인 경우

- 이름·대상 역할·구매 목적
- 가격·조합 재료·판매 가격
- 능력치·고유 효과·발동 조건·중복 제한
- 기존 아이템과의 차이, 예상 조합

### 게임 규칙 제안인 경우

- 적용 조건·대상·진행 순서·종료 조건
- 미니언·공성·시야·AI 등 기존 시스템과의 관계

## 예상 영향과 고려할 점

밸런스, 플레이 시간, UI·조작, 성능, 필요한 에셋 등에 어떤 영향이 있나요?

## 검토·검증 방법

기대하는 플레이 예시나 확인 기준을 적어 주세요. 문서 제안만 있다면 코드 테스트 미실행으로 표시해도 됩니다.

## 미정·논의할 점

함께 결정할 사항이나 대안을 적어 주세요.
