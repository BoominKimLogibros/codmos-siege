# 청백 공성전

실행: `npm run dev` 후 `/survival.html` 접속. 실험실 홈의 청백 공성전 링크에서도 시작할 수 있습니다.

## 경기

브라우저 로컬의 **플레이어 대 AI** 공성전입니다. 청팀(왼쪽) 또는 백팀(오른쪽)과 캐릭터 11종 중 한 명을 선택합니다. 전장은 가로 240 × 세로 38의 평면 2D 맵이며 카메라가 플레이어를 따라 좌우로 이동합니다. 브라우저 콘텐츠 영역을 채우고 브라우저 전체화면 API는 사용하지 않습니다.

각 팀은 전방 포탑 2개, 억제기 1개, 넥서스 옆 포탑 2개, 넥서스 1개를 보유합니다. 전방 포탑을 바깥쪽부터 파괴한 다음 억제기, 넥서스 포탑 2개, 넥서스를 차례로 공격합니다. 보호 중인 건물에는 피해를 줄 수 없습니다. 상대 넥서스 파괴로 승리하고 아군 넥서스가 파괴되면 패배합니다. 챔피언 사망은 경기 종료가 아니며 부활 타이머 후 아군 기지에서 돌아옵니다.

미니언은 양 팀에서 9초마다 근접 3기·원거리 2기·기마병 1기가 출발합니다. 억제기를 파괴한 팀은 상대 억제기가 재생될 때까지 강화 미니언을 얻습니다. 억제기는 70초 뒤 재생됩니다. 포탑은 범위 내 적을 자동 공격하고 새 대상을 고를 때 미니언을 우선합니다. 기지 근처에서 챔피언 체력이 회복됩니다.

## 조작

- 방향키 / 우클릭: 챔피언 이동 (멈춰 있을 때만 기본 공격 자동)
- 범위/방향 스킬: 키다운에 범위 표시 → 방향키로 조준점 이동 → 해당 키의 키업에 준비 동작 후 시전. 조준 중에는 캐릭터 이동과 기본 공격을 멈춘다. 마우스로도 조준할 수 있다.
- 타겟팅 스킬: 시야·사거리 안의 유효한 적에게 키다운에 준비 동작 후 사용. 대상이 없으면 비용을 소모하지 않는다. 자기 강화 스킬도 준비 동작 후 사용한다.
- 1~6: 같은 번호의 인벤토리 칸에 있는 소비 아이템 사용
- 미니언 전진/정지/집결은 화면의 명령 버튼으로 조작
- P 버튼: 패시브와 스킬 설명
- 미니맵 클릭: 해당 위치로 이동
- ESC: 조준·상점·사망 기록을 먼저 닫고, 열린 창이 없으면 일시정지. 창 전환 시 자동 일시정지
- 모바일: 조이스틱 이동, QWER 버튼 및 미니언 명령 버튼. 범위 스킬은 버튼을 누른 채 조이스틱으로 조준하고 버튼에서 손을 떼면 시전한다.

청팀·백팀 모두 선택할 수 있고 상대 챔피언은 AI가 이동·전투·스킬·저체력 후퇴를 수행합니다. 네트워크 멀티플레이는 구현하지 않았습니다.

## 캐릭터와 에셋

인트, 나루토, 김정은, 노바, 루시, 제트, 보라, 도깨비, 구미호, 영포티, 단소살인마. 각 캐릭터에 서로 다른 패시브 1개와 액티브 4개가 있습니다. [전체 스킬 목록](SIEGE-SKILLS.md)을 참고하세요. 전투와 미니언 처치로 레벨과 능력치가 자동 성장합니다.

캐릭터는 첨부 ZIP에서 가져온 `public/survival/character-sprites`의 방향별 PNG 시트와 JSON 재생 정보를 사용합니다. 미니언과 배경은 https://codmos-creator-studio.bm33728090.chatgpt.site/#assets 에서 내려받은 로컬 에셋을 활용합니다. `public/survival/library/manifest.json`은 원본 ID·URL·로컬 경로·해시를 기록하며, `sprite.json`에는 정확한 프레임 재생 정보를 보관합니다. 성·포탑·억제기는 2D 캔버스 그림으로 표시하고 팀 색상과 체력 막대를 붙입니다.

## 2026-10-27 방향별 스프라이트 / 피격 표시

현재 선택 가능한 11종을 첨부 `codmos-53-characters-sprites-20261027.zip`의 해당 캐릭터 시트로 교체했습니다. 패키지 전체 53종 중 기존 게임 캐릭터에 필요한 11종의 176개 클립(PNG+JSON 352개 파일)만 `public/survival/character-sprites`에 복사했습니다. 원본 manifest와 README 및 사용 목록 `USED.json`을 함께 보관합니다.

- 위: back, 아래: front, 왼쪽: side_left, 오른쪽: side_right. 정지 시 마지막 방향 유지
- JSON 프레임별 duration(ms), 2px 간격이 있는 정확한 프레임 사각형, meta.anchor를 사용
- 좌측 시트에는 이미 반전이 적용돼 있어 별도로 다시 반전하지 않음
- 실제 플레이하는 두 캐릭터의 모션만 경기 시작 시 로딩. 사용하지 않는 방향별 텍스처는 정리
- 피격 시 개체의 몸만 붉게 tint. 약 0.24초 후 원래 색 복귀. 체력 막대·팀 표시에는 tint/반전 미적용
- 고블린 미니언으로 외형 통일. 병종별 체력·사거리·능력치 차이는 유지
- 고블린 이동은 원본 idle 타임라인의 다리 동작을 반복하며, 정지 시 첫 프레임 유지. 공격(attack)·피격(stun)·생성(spawn)·사망(die)은 각자 원본 클립을 재생
- 원본 고블린은 왼쪽을 바라봄. 오른쪽으로 갈 때 UV와 anchor를 함께 반전하고, 왼쪽 이동 시 원래 값으로 복원. Three.js Sprite가 음수 scale 부호를 버리는 점을 반영했으며 유닛 루트/HP 막대의 scaleX는 항상 양수 유지
- 몸마다 별도 material과 프레임 시계 사용. 같은 이미지의 다른 개체가 함께 tint되거나 모션이 동기화되지 않음

추가 검증:

```sh
node scripts/test-survival-sprites.mjs
node scripts/check-survival-sprites-browser.mjs
```

## 고블린 팀 색상

청팀과 백팀은 `public/survival/goblin/blue` 및 `white`에 저장된 별도 PNG 시트를 사용합니다. 청팀은 azure/cyan 몸과 남색 옷, 백팀은 pearl/ivory 몸과 은회색 옷입니다. idle·attack·stun·die·spawn 5개 클립을 각각 변환했고 프레임 크기·좌표·anchor·alpha를 유지합니다. 이미지 생성 도구의 색상 시안은 팀 선택 아이콘에 사용하고 실제 애니메이션 시트는 원본 픽셀 좌표에 같은 팀 팔레트를 적용해 흔들림을 방지합니다. `TEAM-ART.md`, `PROMPTS.json`, `TEAM-PALETTES.json`에 생성 방법·프롬프트·검증 결과를 기록합니다. 기존 붉은 피격 tint와 초록색 체력 막대는 유지합니다.

## 원거리 / 기마병 / 메소

- 근접 3기는 기존 청색·백색 고블린을 유지합니다.
- 원거리 2기는 첨부 `codmos-assets-7`의 마법 고블린을 사용합니다. 공격은 magic, 피격은 stun, 생성·사망은 해당 모션입니다. 첨부에 없는 idle은 같은 sourceId의 기존 로컬 시트를 사용합니다.
- 기마병 1기는 `codmos-assets-8.zip`의 default 스킨 idle·attack·attacked·stun·spawn·die를 사용합니다.
- 새 병종도 원본 좌표·투명도를 보존한 청팀/백팀 색상 시트를 별도로 저장합니다. 파일은 `public/survival/minions/caster`, `cavalry`에 있습니다.
- 막타 시 몬스터 위로 메소 획득량이 떠오르고, 하단 보유 메소와 CS가 갱신됩니다. 보상은 근접 20 / 원거리 14 / 기마병 50부터 시작합니다.
- 수치와 귀속 규칙, 출처는 [MINION-BALANCE.md](MINION-BALANCE.md)에 있습니다.

추가 검증: `node scripts/test-survival-minions.mjs`.

## 방향키 두 번 입력 대시

같은 방향키를 250ms 안에 두 번 누르면 대시 상태가 됩니다. 두 번째 키를 누르는 동안 기본 이동 속도의 1.85배로 달리고, 키를 떼면 종료됩니다. OS 키 자동 반복이나 서로 다른 방향키의 빠른 연속 입력은 대시를 발동하지 않습니다. 일시정지·창 전환·사망·경기 종료 시 대시 입력과 상태가 초기화됩니다.

좌우 방향은 첨부 ZIP의 `side_left/run`, `side_right/run` 시트를 사용하며, 상하는 해당 방향의 이동 시트를 1.6배 빠르게 재생합니다. 좌우 반전과 발 기준점, 피격 tint는 유지합니다. 이동 뒤쪽에 짧은 흔적을 표시합니다. 달리기 22개 클립을 추가해 사용 중인 캐릭터 클립은 총 176개입니다.

검증: `node scripts/test-survival-dash.mjs`.

범위 스킬 조준 중 Esc는 취소만 하며, 조준이 없으면 일시정지한다. 전체 입력 분류와 범위 판정은 [스킬 입력](SKILL-INPUT.md)을 참고한다.

## 넥서스 상점

넥서스 아래의 상점을 클릭하거나 B 키/가방 버튼으로 연다. 거래는 아군 상점 근처에서 가능하다. 시작 300메소, 인벤토리 6칸, 17종 아이템과 재료 조합/판매를 지원한다. [아이템 목록과 거래 규칙](ITEM-SHOP.md).

## 스킬 배우기 / 최대 레벨

스킬 위 + 버튼이나 Ctrl+Q/W/E/R로 포인트를 사용한다. 미습득 스킬은 사용할 수 없다. QWE 5단계(1/3/5/7/9), R 3단계(6/11/16), 최대 18레벨. [단계별 성장 규칙](SKILL-PROGRESSION.md).

## 사망 피해 기록

사망 시 최근 10초의 실제 체력 피해를 공격자·스킬별로 보여준다. 물리/마법/고정 피해, 보호막 흡수량, 마지막 타격을 구분한다. 방어력·저항력 적용 후의 수치이며 초과 피해를 제외한다. 같은 종류의 미니언은 묶고, 투사체·지속 피해는 공격자가 사라져도 출처를 유지한다. 부활하면 자동으로 닫히고 우측 상단 해골 버튼으로 최근 기록을 다시 볼 수 있다. 기록을 보는 동안 전투는 계속 진행된다.

## 공격·방어 제스처 에셋

추가 첨부 codmos-53-characters-attack-defend-20261027.zip에서 현재 11캐릭터의 4방향 attack/defend 88개 클립(PNG/JSON 176개 파일)을 기존 캐릭터 디렉터리에 복사했다. 기존 manifest는 보존하고 추가 패키지 정보와 사용 목록은 ATTACK-DEFEND-*로 보관한다. 경기 시작 시 실제 두 캐릭터의 공격/방어 모션까지 미리 로딩한다. 준비 시간과 중단 규칙은 [스킬 입력 문서](SKILL-INPUT.md)를 따른다.

## 체력바 눈금

캐릭터·미니언·건물의 월드 체력바는 최대 체력 100당 한 칸으로 나눈다. 최대 400은 4칸, 450은 4칸과 반 칸이며 현재 체력이 줄어도 눈금 위치는 고정된다. 기존 왼쪽 기준의 부드러운 감소와 바 너비를 유지한다. 눈금은 바 내부에만 그리며 고체력의 촘촘한 눈금은 픽셀 밀도에 따라 부드럽게 처리한다. 최대 체력이 바뀌면 눈금도 즉시 갱신한다. 관련 파일: health-bar.js, 검증: check-survival-health-ticks-browser.mjs.

평타·스킬의 몸 제스처 중에는 이동을 잠근다. 걷기/대시 중 평타는 발생하지 않으며, 달리다가 스킬을 사용하면 멈춰서 제스처를 마친 뒤 누르고 있는 방향으로 이동을 재개한다.
