# 레벨 18 및 스킬 포인트

모든 11종 캐릭터와 상대 AI에 동일한 규칙을 적용한다.

- 챔피언은 1레벨, 미습득 Q/W/E/R, 스킬 포인트 1개로 시작한다. 패시브는 항상 적용한다.
- 레벨업마다 포인트 1개. 최대 18레벨이므로 총 18개를 배분한다. 18레벨에서는 경험치/추가 포인트/레벨 능력치 성장이 중단되며 경험치가 0으로 정리된다.
- Q/W/E는 각각 최대 5단계, 다음 단계의 챔피언 최소 레벨은 1 / 3 / 5 / 7 / 9.
- R은 최대 3단계, 6 / 11 / 16레벨에 투자할 수 있다. 포인트를 다른 곳에 썼다면 다음 레벨까지 기다리거나 저장한 포인트를 사용한다.
- 스킬 위 + 버튼 또는 Ctrl+Q/W/E/R로 투자한다. 단축키는 스킬을 시전하지 않으며 조준 중이면 강화 시 조준을 취소한다.
- 미습득 스킬은 조준/시전되지 않는다. 습득한 스킬의 타겟팅/누르고 조준/키업 시전 방식은 그대로다.
- 강화에 마나가 들지 않으며 현재 쿨다운을 줄이거나 초기화하지 않는다. 학습 단계와 미사용 포인트는 사망/부활 후에도 유지하고, 새 경기에서 초기화한다. 사망 중에도 포인트 배분은 가능하다.
- HUD에 단계 점, 미사용 포인트, 경험치 진행, 18레벨 MAX를 표시한다. + 툴팁에는 현재 → 다음 단계 변화가 나온다. P/일시정지 정보에도 현재 단계와 효과를 표시한다.
- AI는 동일한 포인트/레벨 제한을 지켜 R 우선, Q 우선, 나머지 캐릭터별 순서로 자동 투자한다.

## 단계별 강화

이 게임의 캐릭터 스킬을 위한 자체 수치다. 1단계는 기존 스킬 값과 같다.

- 일반 스킬 피해는 추가 단계마다 기본값의 28% 증가, 궁극기는 50% 증가. 반올림 정수 값을 사용한다.
- 일반 스킬 쿨다운은 단계마다 기본값의 10% 감소(5단계 60%), 궁극기는 15% 감소(3단계 70%). 스킬 가속은 이후에 적용한다.
- 마나 비용은 일반 스킬 단계마다 +3, 궁극기는 +10.
- 회복/보호막은 일반 스킬 단계마다 기본값의 30%, 궁극기는 50% 증가.
- 지속 시간은 일반 +0.5초 / 궁극기 +1초, 이동 배율 +0.06, 공속 강화 배율 +0.15씩 증가한다.
- 기절은 일반 +0.1초 / 궁극기 +0.2초, 둔화 지속 +0.25초. 독 지속 +0.5초, 독 기본 초당 피해 +20%씩 증가한다.
- 사거리/범위/이동 거리는 유지해 기존 조준 표시와 판정을 보존한다. AP/추가 AD 계수는 유지하며, 챔피언 레벨만으로 스킬의 기본 피해를 올리던 기존 배율은 제거했다.
