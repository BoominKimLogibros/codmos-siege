# 스킬 입력과 조준

44개 스킬: 타겟팅 5 / 직접 사용 8 / 범위·방향 조준 30 / 방향키 지정 1. 각 정의는 kits.js의 INPUTS와 공유한다. 아래 입력은 시전 준비를 시작하며, 실제 효과는 준비 동작 이후 발생한다.

- 타겟팅: 키다운에 대상을 확정하고 준비 동작을 시작한다. 마우스로 가리킨 유효한 적을 우선하고, 없으면 사거리 안의 챔피언 → 미니언 → 허용된 건물 순으로 선택한다. 시야 밖·사망·무적·사거리 밖·보호된 건물은 제외한다. 대상이 없으면 마나/쿨다운을 쓰지 않는다.
- 범위/방향: 키다운에 표시, 방향키로 조준점을 이동, 해당 키의 키업에 조준을 확정하고 준비 동작을 시작한다. 캐릭터와 자동 공격은 조준 중에 멈추지만 전투 시간/적은 계속 움직인다. 조준은 자원 소모 없이 시작하고 키업 때 상태를 재검사해 비용을 지불한다.
- Esc: 조준 중이면 취소만 하고 일시정지하지 않는다. 취소 후 해당 스킬 키를 놓아도 발사되지 않는다. 남아 있는 방향키 입력은 이동으로 복귀한다. 조준이 없으면 기존처럼 일시정지다. 우클릭/미니맵 이동, S 정지, 일시정지/포커스 상실/사망/침묵/기절도 조준을 취소한다. 조준 진입 시 새 더블탭 기록은 지우되 이미 달리는 상태와 누르고 있는 방향키는 보존한다.
- 모바일 스킬 버튼도 포인터 다운/업을 사용한다. 조이스틱은 버튼을 누르는 동안 조준점을 옮긴다.
- 원형 범위, 실제 폭의 직선, 부채꼴, 돌진 경로, 착지 폭발을 표시한다. 이동을 막는 지형이 있으면 실제 도달 지점과 황색 표시/원래 목적지의 붉은 ×를 보여준다.
- 노바/보라 Q와 구미호 W는 지정한 적을 추적하며 중간 미니언에 가로막히지 않는다. 시야를 잃으면 추적이 중단된다. 보라 E는 선택 대상 흡혈, 구미호 R은 선택 대상에게 3회 접근 공격한다.
- 인트 W/E, 김정은 E, 단소 W는 선택한 지점의 회복/끌어오기/보호막/침묵으로 판정한다. 루시 E는 조준한 목적지로 이동한 뒤 자동 반격한다. 구미호 Q는 표시한 사거리까지 나간 후 시전자에게 돌아온다.

## 준비 동작과 발동

공격 스킬은 attack 모션을 0.32초, 회복·보호막·버프·반사·재생·미니언 지휘·분신·회피는 defend 모션을 0.4초 보여준 뒤 실제 효과가 발생한다. 현재 11개 캐릭터의 QWER 44개와 상대 AI에 동일하게 적용한다.

- 준비 중 이동·기본 공격·다른 스킬 입력을 막아 제스처가 보이게 한다. 발동 후에도 제스처가 끝날 때까지 이동과 평타를 잠근다. attack 0.85초 / defend 1.2초 원본 모션을 끝까지 재생한 뒤 이동을 재개한다.
- 시전 방향을 고정하고 네 방향 원본 프레임과 anchor를 사용한다. 좌우 시트에 추가 반전은 적용하지 않는다. 일반 피격은 tint만 겹쳐 표시하며 준비 동작을 끊지 않는다.
- 마나와 쿨다운은 준비 시작 시 한 번 적용한다. 준비 중 사망·기절·침묵으로 취소되어도 반환하지 않는다. 일시정지는 준비 시간도 멈춘다.
- 범위 스킬의 확정 지점은 준비 중 변경하지 않아 상대가 피할 수 있다. 타겟팅은 발동 시 대상의 생존·시야·사거리·무적·건물 보호 상태를 재검사한다. 유효하지 않으면 발동하지 않는다.
- Esc는 확정 전 조준을 취소한다. 이미 확정한 준비 동작은 Esc로 취소되지 않는다.

검증: test-survival-skill-gestures.mjs (44종 준비/발동/중단/회피), check-survival-skill-gestures-browser.mjs (실제 키·방향별 모션·tint·모바일 입력).

## 캐릭터별 시전 이펙트

첨부 codmos-assets-9의 네 방향 별 이펙트(13프레임/30fps)를 실제 스킬 발동 순간 시전자 몸 위에서 한 번 재생한다. 캐릭터의 HEROES.color로 중심부를 셰이더에서 착색하고 흰색 외곽선과 원본 투명도는 유지한다. 조준·준비 동작·취소된 스킬에는 표시하지 않는다. 공격/버프/회복/보호막/이동 등 44개 스킬에 공통 적용한다.

이펙트는 약 0.433초 동안 시전자 위치를 따라가며 돌진/순간이동 후에도 해당 캐릭터 위에 표시된다. 방향은 발동 방향에 맞춰 고정하고, 블루팀/레드팀 색 대신 캐릭터 색상을 사용한다. 일시정지 시 재생도 멈춘다. 원본 PNG/JSON 및 SHA manifest는 public/survival/effects/cast에 보관한다.

관련 파일: cast-effect-spec.js / cast-effects.js, engine.js의 executeSkill 및 효과 위치 갱신. 검증: test-survival-cast-effects.mjs (44종·파일 해시·프레임·색·시전자 추적), check-survival-cast-effects-browser.mjs (11캐릭터 실제 발동·셰이더·모바일).

## 기본 공격 제스처

챔피언·같은 스프라이트를 쓰는 분신은 평타마다 네 방향 attack 모션을 새로 시작한다. 공격 주기의 85% 안에 원본 0.85초 모션을 재생하므로 공속 1.0은 0.85초, 공속 2.5는 0.34초가 걸린다. 아이템·레벨·공속 버프를 반영한 실제 공격 주기를 기준으로 계산한다.

걷기·대시·우클릭 이동 중에는 평타가 발생하지 않는다. 평타를 시작하면 공격 제스처가 끝날 때까지 이동을 잠근다. 기존 피해/투사체 발생 시점은 유지한다. 공격 모션은 대상 방향을 향하며 피격 tint를 함께 표시한다. 스킬 준비 시작 시 진행 중인 평타 제스처를 종료하며, 스킬 제스처 전체가 끝날 때까지 평타는 발생하지 않는다. 기절·사망 시 종료하고 일시정지 시 재생도 정지한다. 검증: test-survival-basic-gestures.mjs 및 check-survival-basic-gestures-browser.mjs.

## 버프·패시브 체력 변화

첨부 codmos-assets-10.zip의 HP Up / HP Down 모션을 체력이 변한 대상 머리 위에 겹쳐 표시한다. 시전자 대신 실제 회복/피해를 받은 대상에 붙으며, 이동을 따라가고 몸의 공격·스킬 모션을 대체하지 않는다.

- 초록색 HP Up: 인트의 아군 회복, 인트/영포티 패시브 재생, 영포티 W 지속 회복, 구미호 패시브·아이템 흡혈, 보라 E 흡수, 체력 물약.
- 붉은색 HP Down: 독 등 지속 피해, 반사 버프 피해, 나루토/루시/제트 강화 평타, 노바/단소 추가 패시브 피해, 김정은 지휘 버프로 강화된 미니언 피해.
- 실제 체력 변화가 있어야 표시한다. 일반 피격은 tint만 유지하며 보호막만 변한 경우, 체력이 가득 찬 상태의 회복, 기본 능력치 재생/기지 회복/구매/레벨업/부활에는 화살표를 추가하지 않는다.
- 21프레임을 30fps로 한 번 재생한다(0.7초). 같은 대상·같은 방향의 연속 변화는 하나로 모으고 재생을 리셋하지 않는다. 지속 효과는 최소 0.85초 간격으로 다시 표시한다. 일시정지 시 재생도 정지한다.

원본 및 사용 목록: public/survival/effects/health. 관련 파일: health-effects.js, engine.js의 restoreHp/healthChangeEffect. 검증: test-survival-health-effects.mjs, check-survival-health-effects-browser.mjs.

## 전투 중 이동 잠금

방향키·조이스틱·우클릭 목적지 이동은 평타/스킬 몸 제스처 전체가 끝날 때까지 잠근다. 달리는 중에도 스킬 사용은 가능하며, 조준/시전이 시작되면 멈춘다. 방향키를 계속 누르면 제스처가 끝난 뒤 이동을 자동으로 재개하고, 기존 대시 상태도 유지한다. 방향키를 모두 떼거나 S를 누르면 이동 재개를 취소한다. 이동 스킬 자체의 돌진/순간이동은 정상 적용되며, 체력 화살표 같은 별도 이펙트는 이동을 잠그지 않는다. 검증: test-survival-combat-movement.mjs 및 check-survival-combat-movement-browser.mjs.

## 나루토 근접 나선환과 분신 연계

- 평타는 사거리 3.1(표시 스탯 155)의 근접 공격이다. 평타 투사체를 생성하지 않는다.
- Q는 키다운 당시 누른 방향키/조이스틱 방향으로 시전한다. 입력이 없으면 마지막 바라보던 방향을 사용하고 마우스 위치나 자동 타겟팅을 사용하지 않는다. 대각선도 정규화한다. 0.32초 공격 준비 후 0.18초 동안 3.6만큼 짧게 돌진하며 손앞의 나선환으로 근접 경로를 타격한다. 지형과 구조물 충돌을 지키고, 벽 너머에는 피해를 주지 않는다. 같은 적에게는 시전자당 1회만 피해를 준다.
- W 분신 수는 1/2/3/4/5단계에서 1/2/3/4/5명. 본체 주변의 통과 가능한 위치로 분산 소환하며 재사용하면 기존 본인 분신을 교체한다. 분신의 기존 평타·체력·수명과 보상 귀속 규칙은 유지한다.
- 분신이 있을 때 본체가 Q를 쓰면 살아 있고 행동 가능한 분신도 같은 방향으로 준비·돌진·나선환을 시전한다. 분신 Q는 본체의 Q 단계/주문력/추가 공격력/관통을 적용하고 본체에게만 마나·쿨다운을 한 번 부과한다. 본체가 준비 중 사망/제어 효과로 취소되면 연계 준비도 취소된다.
- 본체·분신 모두 시전 제스처 동안 일반 이동과 평타는 잠기며, 각자 시전 색상 이펙트와 손앞의 회전 나선환을 표시한다. E/R은 기존 기술을 유지한다.

검증: test-survival-naruto.mjs, check-survival-naruto-browser.mjs 및 스탯/스킬 입력/레벨업/제스처/충돌 테스트.
