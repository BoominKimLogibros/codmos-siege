# CODMOS 공성전 타일 맵

240 × 40 크기의 단일 가로 맵. 지형 단위는 4 × 4이며, 바닥은 연속된 1.8 단위 석재 포장, 원형 기지 광장, 포탑 주변 광장, 초원 샛길, 연못으로 디자인한다. 기존 2D 캐릭터와 카메라를 유지한다.

## 원본과 제작 이미지

- 사용자가 제공한 `/Users/logibros/Downloads/codmos-tile-assets/`에서 22개 원본 PNG를 `public/survival/map/`으로 복사했다. 원본 해시와 메타데이터: `sources.json`.
- 포탑/억제기/넥서스의 블루팀/레드팀 6개 이미지는 첨부 바위·나무·풀을 참조하여 built-in `image_gen`으로 생성했다. 최종 프롬프트와 후속 투명 배경 정리 프롬프트: `GENERATION.json`.
- `structures-clean-atlas.png`가 최종 생성 원본이다. 각 건물의 알파 연결 영역에 맞춰 개별 PNG를 잘랐으며 생성된 색상과 알파를 유지했다. `structures-atlas.png`는 첫 생성본이다.

## 이동과 시야

- `src/survival/map-layout.js`가 그림, 충돌, 길찾기, 수풀 판정의 단일 기준이다.
- 바위·나무 줄기·연못의 물·살아 있는 건물 받침대를 통과할 수 없다. `footprints.js`의 타원형 바닥 접지 영역을 렌더링과 이동 충돌이 공유한다. 공격 사거리용 원형 `r`과 이동 충돌은 별개이며 챔피언의 이동 반경은 0.35이다. 나뭇잎이나 포탑 아래 빈 바닥은 통과할 수 있다. 대시/돌진/강제 이동도 작은 구간으로 나눠 검사한다. 장애물 옆에서는 축별로 미끄러지며 이동한다. 파괴된 건물은 충돌이 해제된다.
- 나무는 줄기만 충돌하며, 조작 캐릭터가 잎 뒤로 지나갈 때 반투명하게 보여 가려지지 않는다. 바위는 지형 색조에 맞춰 렌더링하며 받침/뿌리/물가의 윤곽으로 막힌 영역을 표시한다.
- 미니언, AI, 우클릭 이동은 막힌 구간에서 2단위 격자 A* 경로를 따라 우회한다. 방향키는 직접 조작으로 유지한다.
- 빽빽한 수풀 12곳은 들어갈 수 있다. 수풀 안의 적은 월드 캐릭터·체력바·미니맵에서 숨고, 적 AI·포탑의 자동 타깃에서도 제외된다. 같은 수풀 안의 아군이 있으면 팀 전체가 적을 볼 수 있다.
- 기본 공격이나 스킬 사용은 1.2초 동안 시야를 드러낸다. 수풀에서 나가면 바로 보인다. 지면 조준 스킬은 보이지 않는 적에게도 적중할 수 있다.
- 아군 수풀 캐릭터는 반투명하게 보이고, 조작 캐릭터가 들어간 수풀 잎도 옅어져 위치를 확인할 수 있다.

검증: `node scripts/test-survival-terrain.mjs`, `node scripts/check-survival-terrain-browser.mjs`.

## 팀 시야와 전장의 안개

- `vision.js`의 공통 판정으로 양 팀에 동일한 시야 규칙을 적용한다. 살아 있는 챔피언(16), 미니언(11), 분신(9), 포탑/기지 포탑(16), 억제기(12), 넥서스(18)가 팀 전체에 시야를 제공한다. 사망·파괴되면 시야가 사라진다.
- 나무 수관과 바위는 시야를 가린다. 이동은 기존의 좁은 줄기/받침 충돌을 유지한다. 나무 안쪽의 관측자는 밖을 볼 수 있으므로 직접 들어가 정찰할 수 있다. 연못과 건물은 시야를 차단하지 않는다.
- 시야 밖 적 캐릭터·미니언·건물·체력바·투사체·효과·미니맵 아이콘은 표시하지 않는다. 자동 공격/유도 스킬/포탑 타깃도 같은 판정을 쓴다. 적이 시야를 벗어나면 유도 공격 추적을 해제한다.
- 수풀은 기존처럼 같은 수풀의 아군이 필요하다. 공격으로 1.2초간 수풀 은신이 풀려도 아군 시야 거리와 지형 차단 판정을 통과해야 보인다.
- `fog.js`는 같은 시야 차단 데이터를 사용해 관측자별 가시 다각형을 그린다. 안 보이는 지형은 어두운 안개로 표현하고 미니맵도 같은 마스크를 공유한다. 적의 마지막 위치를 남기지 않는다.
- 나무 뒤의 유닛이 실제로 보이는 상태가 되면 나뭇잎도 반투명해져 아군 정찰로 발견한 대상을 확인할 수 있다.

검증: `node scripts/test-survival-vision.mjs`, `node scripts/check-survival-vision-browser.mjs`.

외곽 배경은 `SCENERY` 범위(288 × 88)까지 이어진다. 실제 이동 영역은 240 × 40 그대로이며, 숲 바닥 색이 불규칙하게 짙어지고 여러 겹의 나무/풀이 경계를 감싼다. 전장의 안개도 같은 외곽 범위에 렌더링해 사각 절단선을 없앴다. 미니맵은 확장된 바닥/안개에서 플레이 영역만 잘라 기존 좌표를 유지한다. 양끝 진격로는 기지 원형 광장 안에서 끝난다.

## 포탑 파괴 스프라이트

전방 포탑(tower)과 기지 포탑(guard)이 파괴되면 포탑 본체·체력바·충돌은 즉시 제거되고, 해당 위치에 smoke/돌 파편 스프라이트를 1회 재생한다. 파일은 spine_0c85c02efa_default_idle.png, 원본 SHA-256 edfc3d0a63a000b731ed14f151a41a149ae94faaf5c65f094e779218c60cbca8. 공통 리소스의 bundle.zip에서 PNG·sprite.json·asset-manifest.json을 함께 다운로드해 public/survival/effects/tower-collapse에 저장했다.

1024×1004 시트를 256×251 프레임으로 잘라 총 15프레임을 30fps로 재생한다(0.5초). 원본 bounds.origin을 사용하고 재생 종료 시 개별 재질/UV 텍스처를 정리한다. 일시정지 중에는 프레임도 정지한다. 억제기·넥서스의 기존 파괴 처리는 유지한다. 구현: tower-collapse.js / tower-collapse-spec.js. 검증: check-survival-tower-collapse-browser.mjs.
