# 넥서스 상점과 아이템

양 팀 넥서스 아래쪽, 블루팀 (-111, 9) / 레드팀 (111, 9)에 상점이 있다. 상점을 클릭하면 캐릭터가 걸어가 구매 범위(5 거리)에 도착했을 때 상점이 열린다. B 키/가방 버튼으로 어디서든 상품을 볼 수 있으며, 원거리에서는 구매/판매 버튼이 비활성화된다. 헤더의 '아군 상점으로 이동'으로 실제 이동할 수 있다. 순간이동하지 않는다.

- 시작 자금은 양 팀 챔피언 300메소. 기존 막타 메소와 CS 규칙은 유지한다.
- 살아 있는 챔피언이 아군 상점 범위 안에 있을 때만 구매/판매 가능하다. 원거리·적 상점·사망·일시정지 상태에서는 엔진에서도 거래를 거절한다.
- 보유 6칸, 기본 아이템은 중복 구매할 수 있다. 완성 아이템은 각각 하나, 장화 종류는 한 종류만 보유할 수 있다.
- 상점의 완성품 탭에서 조합 아이템만 모아 보고, 완성품 구매 버튼으로 한 번에 구매한다. 재료 없이도 완성품 정가만 지불하며 중간 재료가 인벤토리 칸을 차지하지 않는다.
- 보유 재료가 있으면 해당 재료의 정가를 차감하고 재료를 소비해 조합한다. 재료가 없어도 완성품을 정가로 구매할 수 있다. 6칸이 가득 차도 재료 소비로 자리가 생기면 조합할 수 있다.
- 장비 칸 또는 상점이 열린 상태의 소비 아이템 칸을 누르고 판매 버튼을 눌러 정가의 70%를 반환받는다. 조합 아이템은 최종 아이템의 정가 기준으로 계산한다.
- 구매는 즉시 장착되며 AD/AP/방어력/저항/체력/마나/재생/공속/이속/치명타/흡혈/관통/스킬 가속에 실제 반영한다. 레벨업 재계산과 부활에도 보유 효과를 유지한다.
- 최대 체력/마나가 변하면 증가분을 현재 수치에 더한다. 판매로 최대 체력이 줄어도 생존 중인 캐릭터는 최소 체력 1을 유지한다. 사망 상태를 거래로 되살릴 수 없다.
- 구매 실패는 메소/인벤토리/능력치를 변경하지 않는다. 새로운 경기는 장비 없이 300메소로 시작한다.
- 상점 UI를 열면 조준/자동 이동/기존 이동 입력을 취소한다. Esc는 상점을 닫기만 하며, 전투는 상점 이용 중에도 계속 진행된다.
- 월드 상점은 Canvas, 아이템 아이콘은 SVG로 구현한 게임 그래픽이며 외부 이미지/서버에 의존하지 않는다.

## 상점주인 스프라이트

레드팀 상점 앞의 주인은 공통 리소스 spine_110411bc31_default_idle.png로 표시한다. 원본 번들에서 PNG·sprite.json·asset-manifest.json을 내려받아 public/survival/shopkeeper에 보관했다. SHA-256: 5e923855fb18c13582f35240573c757a8fda368ee7d827183498580a5accd75b.

908×1024 시트를 227×256의 13프레임으로 잘라 30fps로 반복 재생한다. 원본 bounds.origin을 보존하면서 발 위치를 상점 앞 바닥에 맞춘다. 원본 색상과 양수 스케일을 유지하며 일시정지 시 멈춘다. NPC도 상점 클릭 영역에 포함되고 기존 구매 거리·이동·판매·충돌 규칙은 유지한다. 구현: shopkeeper.js. 검증: check-survival-shopkeeper-browser.mjs, check-survival-shop-browser.mjs.

## 블루팀 전용 상점주인과 상황 모션

블루팀 상점은 codmos-assets-11.zip의 파란 로봇(Spine 1bb99aaaca)으로 표시한다. 상점 팀을 기준으로 외형을 고르므로 레드팀 플레이어가 블루팀 상점을 봐도 파란 로봇이 보이며, 레드팀 상점은 기존 노란 상점주인을 유지한다. 원본과 사용 목록은 public/survival/shopkeeper/blue에 보관한다.

- 평상시 idle, 아군이 구매 범위에 들어오면 hello 1회, 근처에서 상점을 열어 상품을 보면 input. 범위 경계 반복 인사를 막는 여유 거리 2를 둔다.
- 실제 구매·판매 성공 시 calculate. 체력 물약 구매는 계산 후 juice_strawberry, 마나 물약 구매는 juice_grapes를 1회 재생한다. 여러 거래를 빠르게 하면 최근 거래에 맞춰 반응한다.
- 자금 부족 상품을 선택하면 failure, 중복 제한·칸 부족 등 거래 불가능 상품은 error. 선택 상태가 바뀔 때만 한 번 반응하며 매 프레임 반복하지 않는다. 실제 거래 실패도 같은 모션을 사용한다. 적 플레이어가 근처에 오면 hate를 재생한다.
- 동작이 끝나면 현재 상황의 idle/input으로 복귀한다. 일시정지 중에는 프레임과 상태 전환을 멈춘다. 새 경기에서는 과거 거래를 다시 재생하지 않는다.
- 모든 원본 페이지를 프레임 순서대로 사용한다. 두 물약 모션은 각각 120프레임·30fps·2페이지다. bounds.scale 보정으로 동작마다 내보내기 배율이 달라도 캐릭터 크기와 Spine 루트 위치가 튀지 않도록 한다.

검증: test-survival-blue-shopkeeper.mjs (9모션 원본 해시·상태 전환·2페이지·좌표), check-survival-blue-shopkeeper-browser.mjs (실제 접근/상품/구매/판매/실패 동작), 기존 상점 및 상점주인 브라우저 테스트.
